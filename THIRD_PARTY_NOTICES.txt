# Third-Party Notices

The Rust CLI depends on the crates recorded in Cargo.lock. Their license
identifiers and source information are available via `cargo metadata --locked`.
Release archives contain a generated THIRD_PARTY_NOTICES.txt and the license
texts for the dependencies used to build the CLI on the supported platforms.

To generate those files locally, run:

    scripts/bundle-licenses.sh <output-directory>

The script requires Cargo, jq, and the dependency sources downloaded by Cargo.
